
## 全真模拟时间分配

| 题型    | 建议用时    |
| ----- | ------- |
| 完形填空  | 15—20分钟 |
| 阅读理解  | 70—80分钟 |
| 新题型   | 15—20分钟 |
| 翻译    | 20—25分钟 |
| 大小作文  | 40—45分钟 |
| 检查与机动 | 5—10分钟  |
合计约180分钟。

## 二、逐周学习安排

### 第1周：11月3日—11月8日

目标：继续阅读一刷，同时让其他题型全部启动。

根据当天时间情况，具体安排复习目标，逐步建立解题方法
结合网课与真题，尝试掌握
- 阅读 1 已完成
- 完型 1
- 翻译 1
- 新题型 1
- 作文 2


作文方面，这周先花一点时间了解英语二大小作文的基本格式，找一份自己能够理解、记忆的参考模板。不要求立即背熟。

### 第2周：11月9日—11月15日

目标：完成各题型的初步接触，建立基本解题方法。


- 阅读 2
- 完型 1
- 翻译 1
- 新题型 1
- 作文 2


每天仍然保留10分钟单词复习。

这周结束时，不要求所有题型都达到很高正确率，但至少需要做到：拿到题目知道从哪里入手，知道自己容易在哪里失分。

特别注意作文：不要只看老师讲解或背范文，必须自己动笔写。哪怕刚开始写得很差，也比一直看课有效。

### 第3周：11月16日—11月22日

第一次全真模拟

11月22日：2024年英语二真题。

建议在这周前半段继续专项训练：

|内容|安排|
|---|---|
|阅读|2篇，重点分析错误选项|
|完形|1篇|
|新题型|1篇|
|翻译|1组|
|作文|大小作文各写1次|
|全真模拟|11月22日，完整180分钟|

第一次模拟不要过分关注分数。

你要重点记录：

- 阅读用了多少时间，正确率如何？
    
- 作文是否能在规定时间内完成？
    
- 完形、新题型是否出现大面积失分？
    
- 翻译是否因为长难句理解问题而失分？
    
- 是否出现最后几题来不及做的情况？
    

第一次模拟的真正作用，是找出你的整套试卷中的时间和能力短板。

### 第4周：11月23日—11月29日

目标：复盘第一次模拟，集中修补短板。

这一周不安排第二套整卷。

建议这样分配：

|任务|次数|
|---|---|
|第一次模拟卷错题复盘|2次|
|阅读专项练习|2次|
|完形或新题型|1次|
|翻译专项|1次|
|大小作文手写|各1篇|

尤其是阅读，不要只把错误题目重新做对就算结束。要搞清楚自己究竟是单词不认识、句子理解错误、没有找到原文依据，还是被干扰项误导。

如果第一次模拟阅读错得比较多，我建议把本周多出来的时间优先给阅读。

### 第5周：11月30日—12月6日

第二次全真模拟

12月6日：2025年英语二真题。

这周主要任务：

- 复习第一次模拟中暴露出的薄弱点。
    
- 阅读练习1—2篇。
    
- 完形、新题型各练习1篇。
    
- 大小作文各写1篇。
    
- 12月6日完成完整180分钟模拟。
    

第二次模拟重点观察：经过前两周训练，你的做题速度和稳定性是否提高。

不要因为分数比第一次低就急着更换老师或资料。先分析试卷难度和错误原因。

### 第6周：12月7日—12月13日

第三次全真模拟

12月13日：2026年英语二真题。

这是最后一次完整模拟。

这周不再大面积开新课，主要完成：

- 阅读错题复习。
    
- 高频词汇和熟词僻义复习。
    
- 完形、新题型的解题技巧回顾。
    
- 翻译中的长难句分析。
    
- 大小作文模板和常用表达背诵。
    
- 12月13日完成第三次模拟。
    

这一次要尽量完全还原考试环境，包括答题卡、时间限制和作文手写。

### 第7周：12月14日—12月18日

目标：稳定发挥，而不是继续大量刷题。

|内容|建议|
|---|---|
|单词|每天10—15分钟|
|阅读|回顾错题和典型文章，不追求新题数量|
|作文|每天回忆和默写核心结构|
|完形、新题型|回顾常见解题方法|
|翻译|复习之前做错的长难句|
|整套试卷|不再强制安排|

考前一天不建议做高强度英语训练，保持做题手感即可。
