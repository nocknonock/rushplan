# 考研英语二按周独立日程体系与四科笔记隔离实施方案

本方案将《英语最后阶段安排》完整接入备考作战室：针对英语与其他三科（数二、408、政治）“按日推进”不同的节奏特点，构建一套**按周划分（7大周次 + 4大阶段 + 3次固定日全真模考）**的独立数据结构与视图体系；同时将原本跨科目共享的日笔记升级为**四科彻底隔离的独立复盘笔记**，并实现全量数据的无缝备份导入与导出。

## User Review & Critical Decisions

> [!IMPORTANT]
> **已确认的核心产品与交互决策：**
> - **视图布局与首页联动**：日程表新增独立的 **「英语专属日程表（按周视图）」** 页签；同时在「今日仪表盘」首页同步展示当前所处周次的英语打卡进度与任务清单，若当日恰好为全真模考日（11月22日、12月6日、12月13日）则触发专属醒目提示。
> - **多频次任务拆分与动态编辑**：将每周多次任务（如“阅读 2”、“作文 2”）按频次拆分为独立的打卡子项（如 `阅读 第1篇`、`阅读 第2篇`），每勾选一项实时推进本周进度条；且每周支持通过弹窗动态增删打卡项、修改目标与重点指导，或一键恢复默认。
> - **四科复盘笔记彻底隔离**：废除原先单日跨科混用的通用笔记模式。**英语采用独立的按周复盘笔记**（仅在英语视图及英语周记切页中可见）；**数学二、408、政治各自拥有按科隔离的每日专属笔记**，互不串扰。
> - **全量备份导入与导出完备性**：升级 JSON 备份协议，将英语全部 7 周的勾选状态、自定义修改内容、英语周笔记，以及数二/408/政治三科独立的日笔记全部纳入导出文件，并兼容旧版备份文件平滑迁移。

## 1. Overview & Core Concept

考研英语二的冲刺复习具有显著的**“周内弹性分配 + 固定节点整卷模考”**特征。不同于数学二与408每天严格绑定具体章节或某一年份真题，英语需要将任务颗粒度落在**“周任务池”**（每周完成若干篇阅读、完形、新题型、翻译与大小作文手写），并在特定日期（11月22日、12月6日、12月13日）执行严格的 180 分钟整卷全真模拟。

为此，系统在保留数二、408、政治按日时间轴的基础上，平行构建一套**英语按周作战引擎**：
1. **四大阶段与名师方法论顶栏**：清晰呈现 `11.3–11.15 全题型掌握`（2020–2023真题，配齐作文-石磊鹏、翻译-唐静、完型-易熙人、新题型-刘琦推荐标签）、`11.16–11.29 第一次模拟`（2024真题）、`11.30–12.13 第二、三次模拟`（2025、2026真题）与 `12.14–12.18 考前巩固`，并内置 **180分钟考场时间分配表**（完形 15–20m / 阅读 70–80m / 新题型 15–20m / 翻译 20–25m / 大小作文 40–45m / 检查机动 5–10m）。
2. **7大周次独立作战卡片（11月3日—12月18日）**：完整还原文档中第1周至第7周的周目标、拆分后的独立打卡清单、核心方法指导及第1周 `阅读 1（已完成）` 的初始状态。
3. **3次全真模考日精准锚定与五维复盘诊断**：在第3周（11月22日·2024真题）、第5周（12月6日·2025真题）、第6周（12月13日·2026真题）嵌入 180 分钟全真模拟专项模块，并附带五维诊断问题清单（阅读耗时与正确率、作文限时完成度、完形新题型失分、翻译长难句理解、涂卡与时间余量）。

## 2. User Experience & Visual Design

- **高对比度青碧（Teal）视觉语义**：延续作战室统一的暗黑工业战术美学，英语模块采用专属的青碧色调（Teal `#14B8A6`）与数学（靛蓝 Indigo）、408（琥珀 Amber）、政治（玫红 Rose）形成鲜明区分，所有时间配额与周次进度百分比均采用等宽对齐数字（`tabular-nums`）。
- **日程表「英语专属（按周视图）」**：
  - **顶部战略看板**：左侧展示 4 大冲刺阶段时间轴与题型老师速查卡，右侧展示 180 分钟整卷时间分配横向比例尺，支持按阶段快速筛选周次。
  - **周次作战流（第1周 — 第7周）**：当前日期所属周次自动高亮置顶感（带 `当前作战周` 徽章）。每张周卡片包含：
    - **头部栏**：周次编号、起止日期、所属阶段标签、本周完成率进度条（`X / Y 项已打卡`）以及「自定义本周安排」按钮。
    - **独立拆分子项打卡区**：按题型分类标签（阅读 / 完形 / 新题型 / 翻译 / 作文 / 模考 / 复盘）排列独立复选框，点击即可单项打卡或撤销，全部完成时触发庆祝反馈。
    - **全真模拟与重点指导面板**：展示本周核心复习策略；若本周含全真模考（第3、5、6周），以高对比度警示框标出具体模考日期、真题年份与考场还原要求。
    - **本周英语专属复盘笔记区**：卡片底部内嵌独立的英语周记面板，方便记录本周阅读错因或模考复盘总结。
- **今日仪表盘（首页）无缝联动**：
  - **顶部四科进度环/条**：新增「英语二（按周推进）」总体子任务完成率统计，与数二、408、政治并列构成完整四科监控。
  - **今日落地作战清单 — 本周英语作战卡**：根据首页当前选中的日期，自动匹配并渲染对应的「第 X 周英语任务池」。用户无需跳转即可在首页直接勾选本周的阅读第1篇、第2篇或作文任务；若选中日期恰逢 `11月22日`、`12月6日` 或 `12月13日`，卡片顶部高亮弹出 **「今日整卷模考日：180分钟全真模拟」** 提醒。
- **科目笔记隔离体验**：
  - 在「全程时间轴」中切换至 `数学二`、`408`、`政治` 单科视图时，每日卡片仅显示并编辑该科目专属的日笔记；在 `全部科目` 综合视图或首页「战地复盘笔记」模块中，提供清晰的科目页签（`数学二笔记` / `408笔记` / `政治笔记` / `本周英语周记`），彻底杜绝跨科内容混淆。

## 3. Key Product Decisions & Trade-Offs

1. **按周独立数据源 vs 强行塞入每日对象**
   - **决策**：为英语建立独立的 7 周数据结构，通过日期区间映射与每日视图联动，而非将周任务机械平摊到每一天。
   - **理由**：考研冲刺后期每天的数学与408负荷波动较大，英语按周统筹能给予用户最大的日内微调自由度，同时在 3 个关键模考日依然保持精确到日的强提醒。
2. **多频次任务细粒度拆分与自定义扩展**
   - **决策**：将“阅读 2”、“作文 2”、“第一次模拟卷错题复盘 2”拆解为可独立勾选的单项，并提供完整的周计划编辑弹窗（支持新增/删除打卡子项、修改子项名称与分类、编辑本周目标与指导说明、一键重置单周默认数据）。
   - **理由**：避免“做完1篇阅读却无法打卡，必须等2篇全做完才能打钩”的挫败感，同时满足后续根据模考表现动态增加薄弱题型专项训练的需求。
3. **历史笔记兼容与科目隔离升级**
   - **决策**：将每日数据结构中的笔记拆分为 `数学二笔记`、`408笔记`、`政治笔记` 三个独立字段，英语则保存在各周的 `英语周笔记` 字段中；若用户本地已有旧版通用日笔记，首次加载时自动平滑保留至对应科目，确保零数据丢失。

### 核心数据明细与初始化准则
- **第1周初始状态还原**：严格遵照文档标记，第1周（11月3日—11月8日）下的 `阅读 第1篇` 默认设为 `已完成（isCompleted: true）`，其余子项（完型 1、翻译 1、新题型 1、作文 第1篇、作文 第2篇）设为待完成。
- **日期到周次的智能映射**：当用户在首页切换任意日期时：
  - 若日期在 `11月3日—12月18日` 之间，精确匹配第1周至第7周；
  - 若日期在 `11月3日` 之前，展示第1周预热预览与基础单词/阅读衔接提示；
  - 若日期在 `12月19日—12月20日`（初试日），展示英语二考场时间分配表与考前定心提示（12月19日下午 14:00–17:00 英语二正式考试）。
